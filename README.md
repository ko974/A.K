# AWS 2AZ構成のWebサーバー

AWSで、2つのアベイラビリティゾーン（AZ）を使った
冗長構成のWebサーバーを構築しました。

## 構成図


## 使ったサービス
| サービス | 役割 |
|---|---|
| VPC | ネットワーク（10.0.0.0/16） |
| サブネット | パブリック×2、プライベート×2（AZごとに1つずつ） |
| ALB | 2台のEC2にアクセスを振り分ける |
| EC2 | Webサーバー（〇〇） |
| RDS | データベース（〇〇）。プライベートサブネットに配置 |
| セキュリティグループ | 必要なポートだけを許可 |

## 工夫したところ
- DBはプライベートサブネットに置き、インターネットから直接つながらないようにした
- EC2のセキュリティグループは、ALBからの通信だけを許可した
- 片方のAZが止まっても、もう片方でサービスを続けられるようにした

## つまずいたことと解決方法
- 〇〇でつながらなかった → 〇〇を確認したら、〇〇が原因だった
