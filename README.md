# AWS 家族の写真保存サーバー

家族のスマホの写真・動画を自動でバックアップする、自分専用の写真保存サーバーをAWS上に構築しました。
インフラはTerraformでコード化し、一括で作成・削除できるようにしています。

## 構成図

![構成図](diagram.png.pdf)

## できること

- 家族のスマホから、写真・動画が自動でアップロードされる（Nextcloud）
- 写真の本体はS3に保存し、1年たった写真は低コストのストレージへ自動で移動する
- 毎朝、前日の利用料金とサーバーの状態をLINEに通知する（Bedrockで内容を要約）
- 障害が起きたときは、すぐにLINEへ通知する

## 使ったサービス

| 分類 | サービス | 役割 |
|---|---|---|
| ネットワーク | VPC / Internet Gateway | 東京リージョンにネットワークを作成。外向き通信のみIGW経由 |
| ネットワーク | VPCエンドポイント | EC2からS3へ、インターネットを通らずに接続 |
| 接続 | Tailscale（VPN） | スマホ・PCからサーバーへ安全に接続（インバウンド通信は全閉） |
| サーバー | EC2（Ubuntu + Docker） | Nextcloud と PostgreSQL をコンテナで運用 |
| データベース | RDS（オプション） | 変数 `use_rds = true` のときだけ作成。サブネットは2AZ分を用意 |
| ストレージ | S3 / S3 Glacier Instant Retrieval | 写真・動画の本体とDBのバックアップ。1年後に自動で移動 |
| バックアップ | AWS Backup | EC2を毎日バックアップ |
| 運用管理 | Systems Manager | SSHを使わずにサーバーを管理 |
| 監視 | CloudWatch / SNS | 容量・CPUを監視し、異常時に通知 |
| 通知 | EventBridge / Lambda | 毎朝8時に通知メッセージを作成 |
| 通知 | Cost Explorer / Bedrock | 前日の利用料金を取得し、AIで要約 |
| 秘密情報 | Secrets Manager | LINEのトークンやパスワードを保管 |
| IaC | Terraform | すべてのリソースをコードで作成 |

## セキュリティ設計

- EC2からS3へは **IAMロール** で接続し、アクセスキーは使わない
- EBS・S3は AWSマネージドキーで **暗号化**
- **インバウンド通信は全閉**。外からの接続は Tailscale のみ
- 管理は Systems Manager で行い、**SSHのポートを開けない**
- パスワードやトークンは **Secrets Manager** で管理し、コードに書かない
- 写真は **S3のバージョニング** で、誤って消しても戻せるようにする

## 設計方針

- **月4,000円前後**に収まる節約構成
- PostgreSQLはRDSではなく、EC2上のDockerで運用して費用を抑える
- 将来RDSに切り替えられるよう、変数 `use_rds` で選べるようにした
